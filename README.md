# Guess-Your-FutureCareer Guidance Web App

An AI-powered Career Guidance System built using Flask and Machine Learning that helps students discover suitable career paths based on their:

Academic skills 📚
Interests ❤️
Aptitude performance 🧠
Programming & communication skills 💻

The system predicts careers and provides:

Career overview
Required skills
Study suggestions
Learning resources
🚀 Technologies Used
Python
Flask
Scikit-learn
Pandas
NumPy
Joblib
⚙️ Installation
git clone https://github.com/your-username/career-guidance-app.git
cd career-guidance-app
pip install -r requirements.txt
▶️ Run the Project
python app.py

Open in browser:

http://127.0.0.1:5000/
📌 Features

✅ Career Prediction
✅ Aptitude Test
✅ Interest-Based Recommendation
✅ Career Guidance & Resources
✅ Simple Flask UI
